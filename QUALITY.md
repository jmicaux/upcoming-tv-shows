# Quality Standards

This project follows a set of engineering and product quality standards aimed at delivering a simple, reliable and accessible user experience.

The checks below are performed depending on the nature and scope of the project.

---

# Design principles

This project is designed with the following principles in mind:

- User experience first
- Accessibility by design
- Lightweight and browser-first
- Progressive enhancement
- Privacy-friendly
- No unnecessary dependencies
- Simple to maintain

---

# Review process

Every release is manually reviewed and, where appropriate, verified using custom AI-assisted review workflows.

## Accessibility

Reviewed against WCAG 2.2 AA best practices.

Typical checks include:

- Semantic HTML
- Keyboard navigation
- Visible focus indicators
- Screen reader compatibility
- Accessible forms
- Heading hierarchy
- Appropriate ARIA usage
- Color contrast
- Responsive layouts
- Reflow at small viewports
- Accessible dialogs and interactive components

---

## Security

Typical checks include:

- No embedded secrets or credentials
- No unnecessary browser permissions
- Safe handling of external links
- Secure use of third-party APIs
- No third-party trackers (unless explicitly documented)
- Dependency review (when applicable)
- Content Security Policy review (when applicable)
- Input validation (when applicable)

---

## Performance

Typical checks include:

- Lighthouse review
- Minimal JavaScript footprint
- Optimized images and assets
- Efficient rendering
- Browser performance review

---

## SEO

When applicable:

- Page title
- Meta description
- Canonical URL
- Open Graph metadata
- Structured data
- robots.txt
- sitemap.xml

---

## Browser compatibility

Verified on recent versions of:

- Firefox
- Chrome
- Edge

Additional browsers may be tested depending on the project.

---

## Code quality

Typical checks include:

- Code readability
- Consistent naming
- Project structure
- Documentation review
- Removal of unused code
- Error handling

---

# AI-assisted reviews

AI is used as an engineering assistant to help review the project. All final design, implementation and validation decisions remain manual.

Typical review areas include:

- Accessibility
- Security
- Performance
- SEO
- Documentation
- Code quality

---

# Scope

Not every check applies to every project.

The review process is adapted to the project's size, architecture and intended use.
